# 가위바위보 코치

추천 손을 확인하고 상대가 낸 손을 입력하면 다음 판의 손을 제안하는 웹앱입니다. 별도 설치나 외부 의존성 없이 `index.html`만으로 동작합니다.

- 웹앱: https://mjbae.github.io/rps-coach/
- 배포: `.github/workflows/pages.yml`의 GitHub Actions가 `main`의 웹앱 변경을 GitHub Pages에 자동 반영합니다.
- 로컬 실행: `index.html`을 브라우저에서 열거나 `python3 -m http.server 8000`으로 실행합니다.
- 대용량 다운로드 원자료는 저장소에서 제외하며, 웹사이트에는 `index.html`만 배포합니다.

## 가위바위보 단체전 전략 연구

가위바위보 단체전에 쓸 전략을 연구 문헌과 공개 원자료로 검증해 정리한 자료입니다. 결론은 `01_최종전략.md`에 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 1:1 대결 보조 웹앱. 파일 하나로 되어 있고 외부 의존성이 없습니다 |
| `01_최종전략.md` | 최종 전략 문서. 검토자 2명의 지적을 반영한 수정본입니다 |
| `02_검증데이터/wf_result.json` | 5개 분야 리서치의 검증 결과. 항목별 주장, 판정, 근거, 출처 142건이 들어 있습니다 |
| `02_검증데이터/angle*.txt` | 위 JSON에서 분야별로 뽑아 사람이 읽기 쉽게 만든 파일. A 순차 패턴, B 기본 확률·첫 손, C 게임이론·무작위성, D 대면 요인, E 단체전 형식 |
| `02_검증데이터/gaps.txt` | 빈틈 보완 리서치(일본 500명 데이터, 첫 손, 습관이 읽히는 속도, 하나빼기·묵찌빠)와 분야 간 상충 정리 |
| `02_검증데이터/model_report.md` | 정량 모델 보고서(첫 손 기대값, 조건부 대응, 형식별 증폭, 사회자전, 노출 위험) |
| `02_검증데이터/워크플로우_원본출력/` | 리서치·검증 워크플로우와 초안 리뷰 워크플로우의 원본 출력 |
| `03_분석코드/xcheck/` | 최종 문서 수치를 독립 재검증한 스크립트(형식별 확률, 동시 대결, 규칙 방향, 3판 2선승 승률) |
| `03_분석코드/model/` | 정량 모델 스크립트. 매개변수와 출처 ID는 `data.py`, 전체 출력은 `all_outputs.log`에 있습니다 |
| `03_분석코드/` (그 밖) | 리서치·검증 단계에서 쓴 보조 스크립트 |
| `04_원문자료/다운로드/` | 논문 PDF, 공개 원자료(Brockbank & Vul, Moerel, Komai 등), 웹 보관본 |
| `04_원문자료/텍스트추출/` | 논문과 웹페이지에서 추출한 텍스트 |
| `05_초안/리뷰전_초안.md` | 검토 전 초안. 비교용으로 남겨 둔 것입니다 |

## 재현 방법

```bash
python3 -I 03_분석코드/xcheck/formats.py        # 연전·다판제·사회자전 확률
python3 -I 03_분석코드/xcheck/simultaneous.py   # 팀 동시 대결 조합별 승률
python3 -I 03_분석코드/xcheck/rules_check.py    # 규칙 방향을 6개 데이터셋에 적용한 결과
python3 -I 03_분석코드/xcheck/bo3_rules.py      # 규칙별 3판 2선승 승률
```
